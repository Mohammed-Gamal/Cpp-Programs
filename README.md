# 📚 C++ Data Structures & Algorithms

Welcome to the **C++ Data Structures and Algorithms** repository! This repository includes a collection of classic and essential data structures and algorithms implemented in C++ programming language, built with clarity, modularity, and performance in mind as possible.

---

## 🚀 What You'll Find

- ✅ Clean and well-structured C++ implementations
- 📁 Modular files for reuse and easy inclusion
- 📌 Commonly used data structures:
  - Array List
  - Singly, Doubly, and Circular Linked Lists
  - Array & Singly Linked List Stacks
  - Array & Singly Linked List Queues
  - Trees (Binary, BST, AVL, etc.)
  - Graphs (adjacency list/matrix)
  - Hash Tables

- 🔍 Fundamental algorithms:
  - Sorting (Selection, Bubble, Insertion, Merge, Quick, etc.)
  - Searching (Linear, Binary, String Matching)
  - Graph algorithms (DFS, BFS, Dijkstra's)
  - Dynamic Programming patterns
  - Recursion and Backtracking
  - Greedy algorithms
  - Exhaustive search
